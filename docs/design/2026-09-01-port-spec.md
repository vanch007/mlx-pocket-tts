# Pocket TTS standalone MLX port specification

## Boundary

The project implements inference and serving in MLX without importing `mlx_audio` at runtime.
Training code remains upstream-only. The port consumes converted official safetensors and may use
the public community MLX artifact as an English baseline, but it must not claim current upstream
parity from that artifact alone.

## Required feature surface

1. Python load, preset voice, arbitrary reference audio and reusable voice state.
2. Complete and incremental generation, sentence-safe unbounded text chunking.
3. Temperature, sampler steps, noise clamp, EOS threshold and frames-after-EOS controls.
4. CLI generation, voice export, local FastAPI health and streaming WAV endpoint.
5. Official English, French, German, Portuguese, Italian and Spanish configurations, including
   the published 12-layer and 24-layer variants.
6. Reproducible PyTorch-safetensors-to-MLX conversion with strict key and shape audit.

## Acceptance evidence

- Static and unit tests pass without `mlx_audio` installed or imported.
- Real M3 Max generation succeeds for preset voice, streaming and long text.
- Gated weights: arbitrary clone and voice export/import pass when access is available; otherwise
  the result is `pending`, never inferred from preset voices.
- At least one real sample per official language; both 12-layer and 24-layer architecture paths.
- Reports record model revision, wall time, time to first audio, audio duration, RTF, peak memory,
  waveform validity and all skipped/blocked gates.
